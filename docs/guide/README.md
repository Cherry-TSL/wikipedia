## 起源（AI文）

一开始就是给一个叫 TSL 的服务器做的配套客户端，所以叫 TSL Client ，是随意起的，没什么深意。问就是起名废。
至于后来的 Cherry，倒不是起名废突然开窍了。是腐竹给了一个 logo，看着像樱桃，那就叫 Cherry 吧。好歹有了个像样的名字。

这个项目最初的骨架，是直接拿的 [Xplus](https://www.mcmod.cn/modpack/467.html) —— 一个 Minecraft 的老牌整合包。在那个年头，Xplus 的确替不少人省了事。
但到了 TSL Client 这儿，自带的配置，还有一些模组，统统砍掉，只要一个干净的躯壳。不为别的，只是不想被别人说。

之后的日子，就是按自己的口味往里填东西。
没什么宏大的规划，也不搞“精心甄选”那套说辞。
看上了，觉得顺手，就留下。优化类的先保住底线，实用的塞进去干活，视觉上看得舒服。
调配置的标准只有一个，不出问题就行。
本来就是打算给别人用的东西，键位也好，HUD也好，都尽量往通用的方向靠。当然也有个人的小调。用久了顺手了，就留着吧
一路上，也没干什么了不起的事，非要说的话，就是没让它散架，也没让那些乱七八糟的东西混进来。版本在往前走，它在后面跟着，没掉队。
从 1.21.4 一路凑合到 1.21.11，没出过什么大岔子，也就这么过来了。

说回这个叫 Cherry 的整合包：不解释，不推销，也不迎合谁的好奇心。只是把自己觉得好用的东西收拾干净，摆在那儿，谁想用就拿去。
有时候回头看，也觉得挺奇妙的——明明是东拼西凑起家的一个包，缝缝补补，竟然也成了某种“自己的形状”。不完美，但合手。

你如果恰好也用得惯，那挺好。用不惯，倒也省事。
