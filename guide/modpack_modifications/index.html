整合包的小改动

约 618 字大约 2 分钟

于 0.7.0 重构了配置

  • Minecraft - 关闭“视角摇晃”。将Mojang Studios加载屏幕的背景颜色更改为黑色。
  • Advancements Reloaded - 成就界面背景样式：ACHIEVEMENT（成就背景）
  • Better Block Entities - 不优化潜影盒
  • Chat Tools - 禁用聊天气泡、时间戳。启用“启用预览点击事件”。启用聊天压缩 严格模式
  • ChatHeads - 渲染位置：在聊天消息行前
  • Chunks Fade In - 区块淡出时间 0.23 秒
  • Cubes Without Borders - 禁用Pause On Lost Focus （失去焦点暂停游戏）。Borderless Fullscreen Type（无边框全屏）修改为 windows:borderless 解决帧数问题
  • Detail Armor Bar - 隐藏空盔甲栏，耐久警报全部关掉
  • Dynamic Crosshair - 不动态隐藏准星，修复准星居中
  • Extreme Sound Muffler - 这个模组没有游戏内配置文件.jpg - 关掉提示，修改屏蔽声源按钮
  • Feather Morph Client - 调整相机高度以匹配当前形态
  • Gnetum - Elements里的全关
  • Inventory Profiles Next - 只保留自动重装、物品整理、物品移动
  • Masa 全家桶 - 未做改动‘不做改动就是最好的改动’
  • Mini HUD - 默认隐藏MiniHUD的主HUD，如需启用，请按 H
  • Mod Menu - 主菜单中的位置：替换掉Realms，禁用更新检测器，简洁列表
  • Modern UI - 关闭 现代提示框、游戏加载提示音。其余选项未改动
  • ModList Memory - 将模式改为“记住滚动的位置”，退出时不保留记录
  • Nametag (Display) Tweaks - 启用名字阴影，背景透明，F1 隐藏HUD视角下名字自动隐藏
  • No Chat Reports - 禁用多人游戏菜单的按钮
  • Peek - 不显示潜影箱内容
  • Roughly Enough Items - 默认不需要拼音语言，搜索框位置改为右下方，收藏夹添加按钮可见度：仅在鼠标在收藏夹时显示
  • Shulker Box Tooltip - 常驻预览浮窗，不显示快捷键提示
  • Simple Block Overlay - 关闭自定义渲染器，选择框颜色设置为 #FFFFFF50（白色，透明度 50%）
  • Simple Shulker Preview - 区分附魔
  • Sodium - 禁用配方弹窗提示/教程弹窗提示。去除世界雾
  • Title Changer - 标题：%modpackName% %modpackVersion% for Minecraft %mcver% %hitokoto%。不会一直更新窗口标题
  • Title Tweaks - Remove Text Shadow（移除标题文本阴影）
  • Xaero's Minimap | Xaero's World Map - 默认显示实体图标，禁用更新检测
  • Zoomify - 缩放动画过渡：淡出 0.2，淡入 0.4，放大倍率为3x，滚动缩放平滑度 50%

其余未列出的模组为默认配置
